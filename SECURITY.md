# Security Policy

## Supported versions

Security reports are welcome for the latest public Terchess version and the current development branch.

## Reporting a vulnerability

Please do not publish credentials, private information, or exploit details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the maintainer through the contact options on the GitHub profile and ask for a private security-reporting channel.

Include the affected version, operating system, steps to reproduce, expected behavior, and actual impact. Do not include secrets or another person's personal data.

## Scope

Terchess is a local terminal chess application that launches a separately installed Stockfish executable. Reports about command execution, unsafe file handling, dependency vulnerabilities, or unexpected network behavior are especially relevant.

Stockfish is a separate project; vulnerabilities in Stockfish itself should also be reported to its maintainers.
